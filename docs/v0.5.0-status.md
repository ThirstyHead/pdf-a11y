## What v0.5.0 is

A desktop GUI (PySide6, optional `[gui]` extra) plus installers, built on the proven
standards-based CLI core (v0.4.0: 18 rules, deterministic remediation). The CLI stays a
first-class, equal client — every capability lands CLI-first; the GUI is a thin shell.

- **Reports:** Markdown (source of truth) → fully-accessible HTML (SMACSS themes) →
  fully-accessible **tagged** PDF that passes our own audit. WCAG 2.2 terminology, one
  section per POUR principle, canonical W3C hyperlinks, social-model-of-disability tone,
  per-file + run-level summary + data-only JSON.
- **Workspace:** immutable originals (source directories are never written), SHA-256
  provenance on every remediated file, append-only history log, progress metrics
  (found / corrected / % improvement — exact in JSON, encouraging in prose).
- **Config:** one text-based TOML file, shared by CLI and GUI (precedence: flag > config
  > default).
- **GUI:** bulk workbench (files or directories, ad-hoc or college-wide), results, report
  format multi-select, progress view over the history log, embedded CLI console (full
  non-interactive parity), settings.
- **Installers:** Windows MSIX (CLI + GUI aliases on PATH) + ZIP; macOS DMG (Developer ID
  signed, notarized) + optional user-level CLI symlink; Linux AppImage + signed .deb.
  CLI-only remains first-class via `pip install pdf-a11y` / `uv tool install pdf-a11y`.
  Every release publishes SHA256SUMS.

## Decisions (2026-09-05 — all recommendations accepted)

- **Q1 → arm64-only** macOS build for v0.5.0 (M4 mini); universal2 is a post-release
  follow-up.
- **Q2 → Sideload-first** Windows: signed MSIX + ZIP, no Store for v0.5.0 ($19/yr Store
  account later if wanted).
- **Q3 → QProcess line-protocol console** in the GUI is acceptable for v0.5.0 (full
  non-interactive CLI parity; real terminal is a v0.6 candidate).
- **Q4 → Regulatory-context blurb** (HB 21-1110 / ADA Title II, explicitly not legal
  advice) in reports, **default OFF**, config-toggled.
- **Q5 → Five starter themes** (light, dark, high-contrast, ocean, forest), user themes
  addable in the config dir.

Key architectural decisions (full text in the local roadmap, D1–D12): report pipeline
md→html→tagged-pdf with self-audit gate; SMACSS plain-CSS themes with contrast-tested
tokens; TOML config at platform-standard paths; workspace copies originals and never
writes to source dirs; improvement metric `(found_before − remaining_after) /
found_before`; PySide6 is LGPL (notice ships in About + README); installer artifacts are
PyInstaller onedir builds; remediated-PDF determinism is preserved (timestamps only in
operational/audit-trail files, never in fix output).
